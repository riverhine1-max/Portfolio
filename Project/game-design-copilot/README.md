# Game Design Copilot (live build)

This folder is the built app that the portfolio links to (`GameDesignCopilot.html` →
"Open the app"). GitHub Pages serves it at `/Portfolio/Project/game-design-copilot/`.
It's an installable web app: Chrome and Edge offer "Install app", and it works offline.

These are generated files: don't edit them by hand. To update the app, change the
source project (github.com/riverhine1-max/Custom-Ai), run `npm run build` there, and
copy everything in its `dist/` folder into this folder (replace the old files).

The Windows download lives on the Custom-Ai repo's Releases page, not here (it's too
big for a normal repo file).
