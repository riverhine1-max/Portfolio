# assets

The studio design system shared by every page.

- `projects.js` — **edit this to add new work.** Every project card, the homepage reel, filters, timeline, and open slots come from here.
- `studio.css` — the stylesheet for the whole site.
- `studio.js` — motion engine (loader, transitions, smooth scroll, cursor, reveals, reel, chapters, video players).
- `work.js` — Work page rendering and the project viewer.
- `lenis.min.js` — smooth scrolling (Lenis 1.3, MIT).
- `*.woff2` — self-hosted fonts: Archivo, Instrument Serif, JetBrains Mono (SIL Open Font License).
