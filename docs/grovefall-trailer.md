# GROVEFALL — gameplay vision

GROVEFALL replaces the portfolio's working title, Samurai Squirrel.

This cinematic trailer visualizes the intended world, traversal and interconnected katana/energy-rifle combat of a future game. It is AI-generated concept footage, not captured gameplay or evidence that these systems are implemented. Summer 2027 is a target release window.

The supplied character turnaround anchors the squirrel hero. Shots are generated with Higgsfield Cinema Studio; the ending and gameplay HUD are composed with Higgsedit. The film combines separate sequences, sound effects and music, with a final Iron Spire reveal.

Portfolio playback is user-controlled with native video controls, inline mobile playback, a poster, no autoplay and no preloading. The direct MP4 link provides a fallback and fullscreen viewing option.

## Delivery

The 119.5-second, 1280 × 720 trailer combines eleven generated sequences with native Higgsedit graphics and a composed ending sound. The embedded file uses H.264/AAC with metadata at the beginning for faster web playback.
